dedup-log

Lazy daily logger that deduplicates closed logs into the Lino .log.lino format.

GitHub · npm · Issue #1

Try it in your browser

The demo runs the deduplication post-processor entirely client-side using a small JavaScript port of the algorithm — no server, no network calls. Paste sample log lines, then click Deduplicate to see the resulting Lino dictionary.

How it works

  1. createDedupLog({ dir }) writes UTC-dated YYYY-MM-DD.log files via log-lazy’s lazy-evaluation interface.
  2. On the first write of a new UTC day, the previous file is closed and deduplino collapses repeated fragments into a local Lino dictionary, producing YYYY-MM-DD.log.lino.
  3. After more than seven days of history, a global dictionary.log.lino is built from the union and each daily file references it via (import dictionary "./dictionary.log.lino").

Install

npm install dedup-log
import { createDedupLog } from 'dedup-log';

const log = createDedupLog({ dir: './logs', level: 'info' });
log(() => `request handled in ${ms}ms`);   // lazy evaluation
log.close();
